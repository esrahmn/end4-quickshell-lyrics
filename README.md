# end4-quickshell-lyrics

A customization of [End-4's Quickshell configuration](https://github.com/end-4/dots-hyprland.git), focused on displaying synchronized lyrics in the media controls.

Lyrics are provided through **LRCLIB**.

## Credits

- Original Quickshell configuration: [End-4](https://github.com/end-4/dots-hyprland.git)
- Lyrics data: [LRCLIB](https://lrclib.net/)

This repository modifies the media-related portion of the original configuration. Please refer to the original project for its license and attribution requirements.
